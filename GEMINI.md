# Тунель P2P для сервера Minecraft (libp2p)

Програмний комплекс забезпечує встановлення прямого мережевого з'єднання між двома вузлами через захищений P2P-тунель. Рішення призначене для маршрутизації трафіку сервера Minecraft за умов відсутності публічної IP-адреси у сторони, що приймає підключення.

## Архітектура та технології

Робота системи базується на мережевому стеку libp2p. Задіяні наступні підсистеми:
* Kademlia DHT та mDNS: Функціонал глобального та локального виявлення вузлів. Пошук здійснюється за попередньо узгодженим криптографічним ідентифікатором (секретним ключем).
* NAT Hole Punching: Механізм проходження через транслятори мережевих адрес (NAT). Забезпечує встановлення прямого однорангового з'єднання з використанням протоколів STUN/TURN без необхідності ручного конфігурування маршрутизаторів.
* TCP-переадресація: Здійснюється інкапсуляція мережевих пакетів цільового порту (25565) у встановлений P2P-потік.

## Інструкція з розгортання

Система налаштована на маршрутизацію стандартизованого порту Minecraft: TCP 25565.

### 1. Компіляція
Команди для створення виконуваного бінарного файлу:
* Середовище Windows: go build -o libp2p.exe
* Середовище Linux: go build -o libp2p
* Крос-компіляція (збірка для Linux у середовищі Windows): $env:GOOS="linux"; $env:GOARCH="amd64"; go build -o libp2p_linux

### 2. Ініціалізація серверного вузла (хост Minecraft)
Виконання команди на комп'ютері, де запущено локальний сервер гри:
./libp2p.exe -host -secret "унікальний-ідентифікатор"

### 3. Ініціалізація клієнтського вузла (гравець)
Виконання команди на комп'ютері для підключення до віддаленого хоста:
./libp2p.exe -client -secret "унікальний-ідентифікатор"

### 4. Встановлення з'єднання у клієнті
Після виводу в термінал повідомлення "ТУНЕЛЬ АКТИВНО" на обох вузлах:
1. Запустіть гру Minecraft.
2. Перейдіть до розділу мережевої гри.
3. Додайте новий сервер, вказавши адресу підключення: 127.0.0.1:25565.
4. Здійсніть підключення.

## Вимоги до експлуатації
* Мережевий екран (Firewall): Операційна система може заблокувати ініціалізацію слухача портів. Потрібне надання системного дозволу на обмін трафіком для скомпільованого файлу.
* Контроль доступу: Параметр secret виконує роль ідентифікатора кімнати та ключа доступу. Вимагається використання криптографічно стійких рядків для запобігання підключенню сторонніх вузлів.
