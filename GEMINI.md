# P2P Tunnel for Moonlight/Sunshine (libp2p)

Цей проект дозволяє двом користувачам з'єднувати свої комп'ютери через захищений P2P-тунель для стрімінгу ігор (Moonlight/Sunshine) або іншого трафіку, навіть якщо вони знаходяться за NAT (без публічної IP-адреси).

## 🚀 Як це працює (Технічна частина)

Програма базується на бібліотеці **libp2p** та використовує кілька ключових технологій:

1.  **Kademlia DHT (Distributed Hash Table):** Замість використання центрального сервера, програма шукає "друга" у глобальній мережі за допомогою спільного секретного слова (`-secret`). Це як пароль для кімнати, де ви зустрічаєтесь.
2.  **NAT Hole Punching:** Програма намагається автоматично "пробити" ваш роутер (NAT) за допомогою протоколів STUN/TURN, щоб встановити пряме з'єднання між комп'ютерами без налаштування Port Forwarding.
3.  **Stream Multiplexing:** Libp2p дозволяє передавати дані багатьох портів (TCP та UDP) через одне єдине з'єднання.
4.  **UDP over TCP Stream:** Оскільки стандартні P2P-стріми гарантують доставку даних, ми загортаємо UDP-пакети Moonlight у ці стріми. Це забезпечує стабільність з'єднання навіть у складних мережах.

## 🛠 Налаштування для Moonlight/Sunshine

За замовчуванням програма прокидає наступні порти:
*   **TCP:** 47984, 47989, 47990, 48010 (Авторизація та керування)
*   **UDP:** 47998, 47999, 48000 (Відео, Аудіо та Геймпад)

### 1. Підготовка
Вам потрібно скомпілювати програму для своєї ОС:
*   **Windows:** `go build -o libp2p.exe`
*   **Linux:** `go build -o libp2p`
*   **Крос-компіляція для друга (з Windows на Linux):** `$env:GOOS="linux"; $env:GOARCH="amd64"; go build -o libp2p_linux`

### 2. Запуск на стороні Host (Sunshine / Ігровий ПК)
```bash
./libp2p.exe -host -secret "ваш-секрет"
```

### 3. Запуск на стороні Client (Moonlight / Ноутбук)
```bash
./libp2p -client -secret "ваш-секрет"
```

### 4. Підключення в Moonlight
Після того, як у обох терміналах з'явиться напис про успішне з'єднання:
1.  Відкрийте клієнт Moonlight.
2.  Натисніть "Add PC" (Додати ПК).
3.  Введіть IP-адресу: **127.0.0.1**

## ⚠️ Важливі зауваження

*   **Брандмауер (Firewall):** На Windows при першому запуску з'явиться вікно з проханням дозволити доступ до мережі — обов'язково дозвольте всі типи мереж (приватні та публічні).
*   **Продуктивність:** Тунелювання UDP через стріми може додати невелику затримку (латентність). Це ціна за можливість працювати без публічної IP-адреси.
*   **Секрет:** Використовуйте довге та унікальне секретне слово, щоб випадкові люди не могли підключитися до вашого тунелю.
